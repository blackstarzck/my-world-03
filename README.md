## 실행

Node.js 22.12 이상이 필요합니다. 현재 확인한 환경은 Node.js 24입니다.

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4183 --strictPort
```

브라우저에서 http://127.0.0.1:4183 을 엽니다. WebGL 2와 하드웨어 가속을 지원하는 최신 브라우저를 사용합니다.

```sh
npm run build
npm run preview -- --host 127.0.0.1 --port 4184 --strictPort
npm test
```

## 관람

- 작은 지도로 로비와 전시실 사이를 이동합니다. 하단에는 이전·다음 버튼과 점 표시로 구성된 작은 페이지네이션을 배치했습니다. 우측 상단의 ‘전체 공간’·‘전체 작품’은 같은 아이콘·텍스트 스타일의 버튼 그룹입니다. 미니맵과 버튼 그룹, 페이지네이션은 같은 반투명 배경과 블러를 사용하며, 낮·저녁 조명에 맞춰 함께 바뀝니다.
- 페이지네이션은 전시된 54점을 순서대로 둘러봅니다. 점 표시는 현재 작품 주변의 최대 7점만 보여주며, 숫자 카운터는 표시하지 않습니다. 선택한 점이 가운데로 오도록 주변 점과 진행 링이 함께 좌우로 부드럽게 이동하며, 이동 중 다시 선택해도 현재 위치에서 새 방향으로 이어집니다. 페이지네이션에 포커스한 상태에서는 좌우 방향키로 탐색하고 Home·End로 처음·마지막 작품으로 이동합니다.
- 활성 점 둘레의 진행 링은 카메라의 실제 경과 시간과 총 이동 시간에 맞춰 채워집니다. 다른 작품으로 재탐색하면 처음부터 시작하며, 도착하면 링이 완성된 뒤 잦아듭니다. 운영체제의 동작 줄이기 설정에서는 이동과 진행 표시가 즉시 완료됩니다.
- ‘전체 작품’은 썸네일·큰 작품명·전시실 이름으로 구성된 전체 화면 목록을 엽니다. 미니맵과 같은 반투명 배경과 블러로 뒤의 전시 공간이 비칩니다. 스크롤바를 숨기고 스크롤은 유지했습니다. 목록의 X·Esc는 현재 관람 화면으로 돌아가며, 항목을 선택하면 카메라 이동과 작품 설명으로 연결됩니다.
- 중앙 로비에는 두께가 있는 아치형 출입구, 곡선 벽의 아치 장식과 몰딩, 장식 기둥, 격자 유리 돔을 적용했습니다. 출입구 폭은 4m를 유지하며 돌출 장식과 기둥 하부에도 이동 충돌 처리를 적용합니다.
- 우측 하단 지도는 천장을 걷어낸 입체 모형입니다. 실제 도면의 곡선 로비·전시벽·가구 배치를 반영하며, 주황색 3D 핀과 바닥 화살표가 현재 위치와 시선 방향을 나타냅니다. 공간 바닥이나 이름을 누르면 이동하며, 이름은 키보드로도 선택할 수 있습니다.
- 드래그로 시선을 돌리고 WASD 또는 방향키로 걷습니다. 기본 이동 속도는 초당 4.5m이며, Shift를 누르면 초당 7.5m로 빠르게 이동합니다.
- 데스크톱 상단의 걷는 사람 아이콘을 누르면 마우스로 시선을 자유롭게 움직입니다. Esc로 종료합니다.
- 휴대폰에서는 터치 드래그로 시선을 돌리고 페이지네이션·미니맵·전체 작품 목록으로 이동합니다.
- 페이지네이션으로 회화·조각을 선택하면 전체 너비의 3D 화면에서 벽·전시 패널·가구를 피해 카메라가 해당 작품 앞으로 이동합니다. ‘작품 감상’이나 전체 작품 목록의 항목, 가까운 작품을 직접 누르면 설명 패널을 엽니다.
- 작품 감상 시 데스크톱 화면은 왼쪽 70%의 3D 작품 영역과 오른쪽 30%의 설명 패널로 나뉩니다. 모바일에서는 작품 영역과 설명을 위아래로 배치합니다.
- 설명 패널 하단의 이전·다음 버튼이나 좌우 방향키로 전체 작품을 순환 탐색합니다. 이동 중에도 다른 작품을 선택할 수 있습니다. X 또는 Esc를 누르면 마지막으로 감상한 작품이 있는 전시실의 정문으로 이동합니다.
- ‘전체 공간’에서는 천장을 걷어낸 모형을 회전·확대할 수 있습니다. 첫 전환 시 멈춤을 줄이기 위해 그래픽 프로그램을 미리 준비하고, 전체 보기에서는 추가 표면 음영 처리를 생략합니다.
- 해/달 버튼으로 환한 낮과 작품 조명을 강조한 어두운 저녁을 전환합니다. 화면 품질은 화면 크기와 렌더링 속도에 맞춰 자동 조절됩니다.

## 도면 반영

기본 치수는 `output/exhibition-design/v2/design-basis.json`의 R02 도면을 따릅니다. 현재 3D 배치는 `src/world/design-basis.json`의 R03이며, 전시벽 8개의 사선 회전을 추가했습니다. 3D 공간의 1단위는 1m입니다. 기존 R02 도면은 이전 배치 기록으로 보관합니다.

| 항목             | 반영 내용                                          |
| ---------------- | -------------------------------------------------- |
| 배치             | 중앙 로비 + 120° 간격의 세 갈래 전시실             |
| 각 전시실        | 내부 폭 12m × 길이 24m                             |
| 천장 높이        | 로비·01·03: 6m / 02: 5m                            |
| 벽·전시실 출입구 | 벽 0.3m / 출입구 4m × 4.2m                         |
| 로비             | 곡선 외벽, 원형 천창 Ø8m, 곡선 벤치 3개, 기둥 3개  |
| 중앙 조형        | 받침 Ø3.6m × 높이 0.45m / 수직 금속 링 외경 2.4m   |
| 전시 패널        | 01·02 각각 4개, 높이 3.6m                          |
| 유리 전시함      | 03에 10개, 각 1.2m × 1.2m × 높이 2.4m              |
| 채광             | 01의 천창 3개, 02의 긴 천창 2개와 보, 03의 측면 창 |

01에는 청록색 벽, 헤링본 원목 바닥, 금속 액자와 천장 몰딩을 적용했습니다. 02에는 노출 콘크리트 벽, 회색 바닥과 긴 천창의 그림자를 적용했습니다. 03에는 밝은 석재 바닥, 검은 금속 프레임의 유리 전시함과 석재·금속 조각을 배치했습니다.

01·02의 독립 전시벽은 각 전시실 입구에서 작품 면을 볼 수 있도록 좌우 대칭의 45도 사선으로 배치했습니다. 벽의 중심 위치와 3m 길이·0.3m 두께·3.6m 높이를 유지하며, 부착 작품·명패·바닥 음영과 충돌 범위도 같은 방향으로 회전합니다. 중앙에는 폭 3m의 연속된 보행 범위를 확보했습니다.

회화는 도면의 배치 중심과 1.5m × 2m 표시 범위 안에서 원본 이미지 비율에 맞춰 액자 크기를 조정했습니다. 소장품 이미지 10점을 반복 배치했으며, 전시 함 내부에는 3D 스캔 초상과 직접 만든 형태 연구 조각을 배치했습니다. 벽·가구·전시대의 이동 충돌을 적용했습니다.

## 모델과 재질

건축과 전시 가구는 도면 치수로 직접 생성하므로 별도 Blender 파일 없이 실행됩니다. 인물 조각은 실제 3D 스캔 모델을 불러옵니다. 질감은 프로젝트 내부에 저장된 실사 기반 재질이며, 표면 굴곡·거칠기·금속 반사·유리 투명도, 천창/창의 채광과 그림자, 물체가 바닥과 만나는 부분의 음영을 함께 사용합니다.

현재 구현은 브라우저에서 돌아가는 실시간 관람 공간입니다. 투명 유리는 성능을 고려한 표현이며 물리적으로 정확한 굴절·전역 조명 렌더링은 아닙니다. 휴대폰에서는 가벼운 품질을 기본 적용하고, 실제 기기 성능에 따라 부드러움은 달라질 수 있습니다.

## 확인 기록

- `npm test`: 이동·충돌, 로비 아치 형상, 미니맵 좌표 일치, 작품 조명, 자동 렌더링 품질, 작품 감상 위치·카메라 경로·이동 중 재탐색·전시실 정문 복귀·이동 시간에 맞춘 진행률 등 24개 검사.
- `npm run build`: 배포용 결과물 생성.
- `output/browser-checks/verification.json`: 실제 Chromium 브라우저 기능 검사.
- `output/browser-checks/gallery-navigation-verification.json`: 페이지네이션·전체 작품 목록·모달 복귀·데스크톱과 모바일 감상 화면 확인 기록. `pagination-*.png`, `collection-index-*.png`에 교체한 UI를 저장했습니다.
- `output/browser-checks/01-lobby.png`부터 번호가 붙은 이미지: 데스크톱과 모바일 화면 검수 자료.
- `tools/verify-browser.cjs`: 브라우저 검사 도구. 로컬 도구 런타임의 Playwright 경로를 사용하며 앱 실행에는 필요하지 않습니다.

재료와 작품의 저작권 및 출처는 [ASSET_LICENSES.md](ASSET_LICENSES.md)에 정리했습니다. 기본 글꼴은 로컬에 포함된 Pretendard Variable이며, 제목에는 Google Fonts의 Noto Serif KR을 사용합니다. 외부 연결이 없으면 제목은 시스템 글꼴로 표시합니다.

작품 감상 화면과 카메라 이동은 [my-world-01](https://github.com/blackstarzck/my-world-01/tree/0791c20)을 참고했습니다. 카메라의 속도·시선·화각 보간을 가져오고, 현재 전시장 도면의 충돌 영역에 맞춘 경로 탐색과 전시실별 정문 복귀를 적용했습니다.

작은 페이지네이션과 전체 화면 작품 목록은 [my-world-02](https://github.com/blackstarzck/my-world-02/tree/6d8f566)의 갤러리 탐색과 목록 레이아웃을 참고했습니다. 현재 전시장의 54점과 70:30 감상 화면에 맞춰 React UI와 카메라 제어를 연결했습니다.
