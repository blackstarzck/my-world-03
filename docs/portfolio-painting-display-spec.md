# 회화 캔버스 적용 사양과 검증

2026-10-20 기준 그림 49점을 실제 전시관에 적용했다. 벽면·패널 39점과 진열장 10곳을 교체했으며, 3개 방과 95개 프로젝트·사례 연결을 유지한다.

## 캔버스

- 앞면 프레임과 매트의 너비는 0이다. 이미지가 앞면 끝까지 이어지며 원본의 여백·종이 질감을 자르지 않는다.
- 측면 두께는 0.03m다. 일반 벽·패널은 가로 1.65m, 끝 벽은 2.25m이며 높이는 7:5 비율로 계산한다.
- 이름표는 그림 바깥에 둔다. 사선 패널에서는 패널 폭을 넘지 않도록 캔버스 아래로 옮긴다.
- 진열장 10곳의 조형물은 가로 1.02m·높이 약 0.729m의 캔버스로 교체했다. 중심 높이 1.45m, 정면 깊이 약 0.152m로 유리 내부에 설치한다. 기존 유리·구조 프레임·받침대와 이동 충돌은 유지한다.
- 카메라는 실제 그림 치수와 정면 법선으로 맞춘다. 49개 위치 모두 정면 접근과 안전한 이동 경로를 검사했다.

## 상세 화면

정면 이동 후 240ms 유지하고, 크림톤의 평평한 전체 화면 레이어를 380ms 동안 페이드인한다. 수직 이동이나 원근 변형을 적용하지 않는다. 모션 감소 설정에서는 이동과 페이드를 생략한다.

기본 화면은 그림이다. 데스크톱에서는 왼쪽 그림·체험을 고정하고 오른쪽 개발 설명만 스크롤한다. 설명 폭은 화면의 40%, 최소 440px·최대 640px이다. 폭 1100px 미만에서는 그림·체험 위, 설명 아래로 쌓는다. 닫기와 확대 조작부는 콘텐츠 밖에 유지한다.

그림은 조작부를 제외한 가용 영역에 contain으로 맞춘다. 확대 모드에서도 7:5 원본 전체를 표시하고 그림에 가로 스크롤이나 자동 크롭을 사용하지 않는다. 창 크기 변경과 회전에도 CSS 가용 공간에 다시 맞춘다. 모바일의 동적 뷰포트와 안전 영역을 반영한다.

승인된 웹앱이 있는 프로젝트만 ‘그림 보기 / 프로젝트 체험’ 전환을 표시한다. 체험 URL이 없는 프로젝트는 탭 없이 그림과 설명만 보여준다. 그림·체험 전환·확대·창 크기 변경 시 같은 iframe을 유지하고, 프로젝트 변경·목록·닫기 시 해제한다. 캡처 뷰어·화면 자료 탭과 관련 코드·데이터 연결은 제거했다.

## 이미지와 데이터

원본 PNG와 평가 기록은 `output/portfolio-paintings-2026-10-20/`에 보존한다. `npm run prepare:paintings`는 검수 통과·원본 SHA-256을 확인하고 다음 자산을 생성한다.

- 전시·목록: 742×530 WebP, 품질 88, 49점 합계 3,145,274바이트.
- 상세: 1484×1060 WebP, 품질 90, 합계 14,358,044바이트. 선택한 그림만 요청한다.
- 대응표: `src/data/painting-assets.json`. 위치 ID별 전시용·상세용 URL, 원본 크기, 대체 설명, 화풍과 원본 해시를 저장한다.

프로젝트 동기화 명령은 그림 대응표·개발 설명을 수정하지 않는다. 실제 재동기화 전후 네 데이터 파일의 해시가 모두 동일함을 확인했다.

## 검증 결과

- `npm test`: 41개 통과. 실제 생성되는 캔버스 49점의 치수·프레임 제거·진열장 내부 배치·정면 모서리·안전 경로 포함.
- `npm run build`: 통과. Three.js 청크 크기에 관한 기존 빌드 안내는 남아 있다.
- 기존 그림 적용 검증은 `output/browser-checks/paintings-v3/report.json`, 화면 자료 제거 이후 검증은 `output/browser-checks/live-experience-only/report.json`에 기록한다.
- 확인 화면: 1920×1080, 1366×768, 1024×768, 390×844, 844×390. 각 화면에서 기본·확대 그림 전체가 화면 안에 있고 가로 넘침이 없음을 검사했다.
- 실제 On the Book 상세·3D 조작, iframe 상태 유지, 체험이 없는 프로젝트의 탭 제거, 하위 프로젝트 전환, 이동 취소, 정면 도착 후 페이드, 키보드 초점 제한·복귀를 확인했다.
- 검토 이미지: `docs/screenshots/paintings/`. 외부 서비스에 상태 변경 요청을 보내지 않고 검사했다.
