# 프로젝트 회화 기획

> 이후 사용자 피드백으로 방별 화풍 통일과 서사 장면 중심 구성은 대체되었다. 현재 기준은 프로젝트별 화풍, 간결한 상징, 넓은 여백이며 필요한 곳에는 포스터와 팝아트를 사용한다. 최종 49점과 개별 평가는 [회화 전체 보기](portfolio-paintings-review.md), 프레임 제거·확대·상세 보기 조건은 [캔버스 적용 사양](portfolio-painting-display-spec.md)을 따른다. 아래 내용은 초기 장면 기획 기록이다.

기존 세 공간의 49개 위치를 프로젝트별 회화로 구성한다. 41개 그룹에 속한 95개 프로젝트·사례 항목을 유지하면서, 사람·장소·사물·자연의 장면으로 각 프로젝트의 특징을 표현한다. 이 기획은 그림을 제작하기 위한 장면과 화풍을 정의한다.

## 전체 구성

| 공간 | 재료와 분위기 | 그림 수 |
|---|---|---:|
| 01 제품과 사용자 | 유화와 아크릴의 색층 | 19 |
| 02 시스템과 개발 프로세스 | 흑연과 잉크에 절제한 수채 | 14 |
| 03 인터랙션과 실험 | 과슈와 색연필 | 16 |

벽면 39점은 현재 액자에 맞는 가로 7:5 회화다. 진열장 10점은 기존 집기 안에 놓는 소형 캔버스·화첩·그림 병풍으로 구상한다. 벽체와 관람 동선은 유지한다.

프로젝트의 이름과 기술 설명은 그림 밖에 둔다. 아래의 가제는 회화 제작을 돕는 내부 기획명이다. 회화적 비유는 실제 기능·성과를 설명하는 문구로 대체하지 않는다.

49점은 현재 물리 위치에 들어갈 기본 회화 수다. 하위 95개 항목의 검색·설명·체험은 유지한다. 각 항목에 대응하는 모티프는 구성의 근거이며, 모든 모티프를 한 그림에 같은 비중으로 그려 넣는 체크리스트가 아니다.

## 그림을 구성하는 기준

- 한 점마다 눈에 들어오는 큰 주제와 행동을 정하고, 주변 모티프는 가까이 볼 때 읽히게 배치한다.
- 앱 화면·대시보드·화살표·코드·수치·로고를 그림 안의 핵심 소재로 사용하지 않는다.
- 같은 방은 재료감과 색조를 공유하되 풍경·인물·정물·실내 장면의 리듬을 만든다.
- 기존 수채·연필·질감 회화 예시는 선과 붓질의 방향을 참고한다. 실제 그림의 인물과 구도를 그대로 복제하지 않는다.
- 첫 제작은 정적인 회화다. 종이 질감·얇고 두꺼운 물감·해칭을 그림 자체의 완성도로 다룬다.

## 01 제품과 사용자

서비스가 사람의 일상에 닿는 순간을 그린 19장의 생활 회화. 제품의 기능을 화면으로 옮기지 않고, 그 기능으로 이어지는 사람의 행동·돌봄·선택·협업을 실제 장소와 사물의 장면으로 번역한다.

주된 표현: 가로 7:5 리넨 캔버스에 그린 서정적 유화. 얇게 겹친 색층과 불투명한 붓질을 섞고, 주인공의 윤곽은 명확하게 두되 주변부의 경계는 부드럽게 풀어 낸다. 나무·천·유리·잎의 재질이 서로 다른 붓질로 느껴지게 한다.

아크릴 밑칠 위의 유화 또는 무광 아크릴 회화. 선택한 초점의 하이라이트에만 제한적인 임파스토를 쓰고, 모든 면을 두꺼운 질감으로 덮지 않는다. 연필·잉크·수채의 방과 구별되는 따뜻한 색층과 붓의 흔적을 공통 언어로 삼는다.

색조: 따뜻한 크림색 밑칠 · 세이지 그린 · 울트라마린 · 번트 시에나 · 제한적인 코럴

19점 모두 가로 7:5이며, 멀리서도 읽히는 큰 실루엣 1개와 보조 색 덩어리 2~3개를 먼저 잡는다. 린넨 결·색층·자연광을 공유하되 인물 근접·무인 정물·넓은 풍경·실내 장면·부감 구도를 번갈아 사용한다. 여섯 법인 홈페이지는 이동서점·강의 황혼·출판 상담·낯선 도시의 도착·북카페·도서관 배송으로 핵심 실루엣과 시점을 다르게 둔다. 그림 안에는 글자·서명·그려진 액자·코드·화살표·UI·로고를 넣지 않는다. 아래 장면은 사업과 개발 기여를 해석한 회화적 비유이며 실재 장소나 수행 기능의 증거로 사용하지 않는다. 내부 회화 가제는 앱의 실제 프로젝트명과 개발자 설명을 대체하지 않는다.

### 도토리 토픽 · 사용자단

위치: A01-01 · 기획 가제: 다시 펼친 아침

낮은 창가에서 한 학습자가 어제 접어 두었던 공책을 다시 펼친다. 전경에는 글씨가 보이지 않는 종이의 눌린 자국과 여러 번 쥐었던 연필, 반쯤 식은 물잔이 놓인다. 중경의 한 손은 이전 장을 짚고 다른 손은 새 장을 준비하며, 배경에는 겨울 가지 끝의 작은 새잎이 보인다. 차가운 창빛이 책상에 닿다가 손 주변에서 따뜻한 살구색으로 바뀐다.

구도: 가로 7:5. 왼쪽 아래에서 오른쪽 위로 이어지는 책상 대각선. 얼굴 전체보다 손·몸의 기울기에 초점을 두고 창밖은 전체 면적의 4분의 1만 사용한다. 화면 오른쪽은 옅은 크림색 빛의 면으로 비워 다시 시작하는 호흡을 만든다.

표현: 아크릴의 따뜻한 밑칠 위 얇은 유화. 손에는 부드러운 색의 중첩, 공책 모서리에는 짧고 불투명한 붓질을 사용한다. 글씨가 보이는 필기는 그리지 않는다.

색조: 크림 · 옅은 청회색 · 살구 · 세이지 · 갈색 흑연

프로젝트와의 연결: 답안 작성·피드백·학습 이력·재연습으로 이어지는 사용자 흐름을 '전날의 흔적을 확인하고 다시 쓰는 행동'으로 비유한다. 공책 장면은 실제 앱 화면이나 학습 성과를 재현한 것이 아니다.

### 도토리 토픽 · 관리자단

위치: A01-02 · 기획 가제: 서가의 열쇠

오래된 자료실에서 관리자가 작은 유리 서랍 하나를 열고 한 권의 자료를 꺼낸다. 전경에는 자물쇠가 달린 나무 서랍과 접힌 면장갑이 있고, 중경에는 닫힌 보관장들과 열린 한 칸이 대비된다. 배경의 큰 창을 통해 사람들이 공부하는 공용 열람실이 옅게 보이지만 자료실과는 낮은 문으로 구분된다. 유리 너머의 빛은 투명하게, 관리자의 손이 닿는 부분은 묵직하게 그린다.

구도: 가로 7:5. 한쪽으로 치우친 3/4 실내 구도. 서랍 손잡이의 반복은 주변부로 물리고 열린 한 칸과 손을 중심으로 시선을 모은다. 금속 열쇠는 작게 그려 보안 아이콘처럼 보이지 않게 한다.

표현: 린넨 위 유화. 나무결은 마른 평붓, 유리는 얇은 색층과 작은 흰 하이라이트, 손은 부드러운 모델링으로 구분한다.

색조: 호두나무 갈색 · 병녹색 · 청회색 · 황동색 · 연한 크림

프로젝트와의 연결: 관리자 조회·변경 권한의 분리, 사용자 데이터와 운영 데이터의 경계, 변경 이력을 다루는 프로젝트를 '필요한 한 칸에만 접근하는 자료실 관리'로 비유한다. 그림 속 보관장은 실제 시스템의 보안 수준을 증명하지 않는다.

### 도토리 문의 관리자

위치: P01-01-F · 기획 가제: 비 오는 날의 답장

작은 상담 창구에 비를 피해 들어온 세 사람이 서로 다른 자세로 자신의 봉투를 기다린다. 전경에는 방금 내려놓은 젖은 우산, 중경에는 봉투를 펴서 답장을 준비하는 담당자의 두 손이 보인다. 아직 묶여 있는 편지와 이미 접어 둔 답장이 질감과 형태로 구분되고, 배경의 흐린 창밖에는 비에 번진 거리만 남는다. 실내의 노란 조명이 젖은 옷자락과 종이 가장자리를 따뜻하게 비춘다.

구도: 가로 7:5. 창구를 가로지르는 낮은 눈높이. 대기 인물은 상반신 일부만 들어오게 하고, 중앙의 손과 열린 봉투가 가장 선명하다. 전경 우산의 곡선과 배경 빗줄기로 수평적인 상담대에 리듬을 준다.

표현: 반투명 유화층의 비 오는 거리와 불투명한 실내 색층을 대비한다. 봉투에는 글씨나 상태별 색상 표식을 넣지 않는다.

색조: 남청 · 노란 실내등 · 우산의 코럴 · 밝은 크림색 · 회갈색

프로젝트와의 연결: 학생·강사·제휴사의 문의를 유형과 처리 상태로 구분하고 상세 답변을 준비하는 흐름을 사람과 편지의 장면으로 번역한다. 상담 창구는 브라우저 저장소 기반 UI 프로토타입의 생활적 비유이며 실제 고객센터 운영을 주장하지 않는다.

### 교육 서비스 화면 연구

위치: P01-01-B · 기획 가제: 수업이 시작되기 직전

작은 배움터의 열린 마당과 회랑을 한 장의 넓은 풍경으로 그린다. 전경의 강사는 수업 자료를 고르고, 바로 옆 학습자는 펼친 공책에서 다음 장을 찾는다. 중경에서는 한 사람이 진열된 교재들을 비교하고 다른 사람은 한 교재의 속장을 자세히 읽으며, 회랑 끝의 운영자는 접이식 의자와 자료를 준비한다. 아침 햇빛이 인물 다섯 명을 똑같이 비추지 않고 마당의 한 부분에서 회랑 안쪽으로 약해진다.

구도: 가로 7:5. 층을 잘라 낸 인포그래픽이 아닌 실제 정원 회랑의 깊이 구도. 왼쪽 전경 두 사람, 중앙의 교재 진열대, 오른쪽 뒤 준비 공간으로 크기와 밀도를 달리한다. 다섯 장면을 테두리나 구획선으로 분할하지 않는다.

표현: 무광 아크릴 회화. 회벽과 돌의 큰 붓질, 인물의 단순한 색 덩어리, 얇은 유약 같은 그림자 색층으로 공동 공간을 만든다.

눈에 보이지 않는 질서를 돌보는 사람들. 서버, 검증, 문서, AI 작업의 추상적인 구조를 사람이 관찰하고 고치고 이어가는 회화적 장면으로 바꾼다.

주된 표현: 흑연 드로잉과 잉크선 위에 투명 수채를 얹은 서사적 회화. 첨부 연필 장미와 인물의 관찰 밀도, 건축 펜수채의 여백을 바탕으로 하되 중심 사물에는 넓은 흑연 명암 덩어리와 분명한 실루엣을 준다. 가는 선은 가까이 갔을 때 발견하는 보조 층이다.

Planit과 VIVE에는 자연물이 현실의 경계를 조금 넘는 시적 초현실 구성을 사용한다. 거래 연작에는 목탄과 과립감 있는 수채를 늘려 불확실성을 표현한다.

색조: 따뜻한 종이색 · 흑연 회색 · 청회색 · 인디고 · 테라코타 · 세이지 그린 · 소량의 호박색

### 문서 통합 관리 서비스

위치: A02-01 · 기획 가제: 여러 실이 한 폭이 되는 오후

햇빛이 낮게 드는 직조 작업실에서 직조공 한 명이 서로 다른 바구니의 실을 같은 천의 무늬에 맞추고 있다. 전경에는 굵기와 색이 다른 실타래, 중경에는 이미 짜인 하나의 넓은 천, 배경에는 각 출처의 짧은 천 조각들이 매달려 있다. 서로 다른 천에도 같은 작은 잎 무늬가 나타나지만, 화면은 작업 도해가 아니라 오후의 노동과 천의 무게를 담은 풍속화로 그린다. 손은 천 아래로 대부분 가려 형태 오류를 줄이고, 청회색 실 한 가닥만 빛을 받게 한다.

구도: 가로 화면. 왼쪽 아래의 다채로운 실에서 중앙의 넓은 천으로 시선이 모인다. 인물은 오른쪽 삼분점에 작게 두고 넓은 천의 곡면과 세로 창빛으로 리듬을 만든다.

표현: 가는 펜 드로잉 + 인디고 중심 수채, 직물에는 마른 붓질

색조: 아마포색 · 인디고 · 녹슨 적색 · 청회색

프로젝트와의 연결: 서로 다른 업체의 엑셀 입력을 하나의 관리 시스템으로 통합한 일을 여러 출처의 실을 하나의 직물로 짜는 행위에 대응시킨다. 반복되는 잎 무늬는 정해진 시트명·컬럼과 DB 컬럼의 명시적인 대응을 뜻한다. 임의 양식을 자동 이해하거나 모든 원본을 실시간 동기화한다는 기능은 암시하지 않는다.

### NestJS 학습

위치: A02-02 · 기획 가제: 서로의 목소리가 닿는 안뜰

한 건물을 둘러싼 세 개의 작은 안뜰에 저녁빛이 차례로 닿는다. 한쪽에서는 주민이 공동 게시판에 종이를 붙이고, 다른 쪽에서는 두 사람이 마주 앉아 이야기하며, 가장 가까운 마루에서는 집주인이 방문객을 맞는다. 종이에는 읽을 수 있는 글자를 쓰지 않는다. 각 생활 공간은 벽과 계단으로 분리되지만 하나의 지붕과 중앙 나무가 전체를 묶는다.

구도: 약간 높은 위치에서 비스듬히 내려다보는 건축 풍경. 중앙의 빈 안뜰이 세 생활 장면 사이의 여백이 된다. 원근과 생활 흔적은 섬세하게 그리고 인물은 작게 둔다.

표현: 건축 펜 앤 워시. 지붕과 벽은 펜, 저녁 그림자는 옅은 수채

색조: 회백색 · 테라코타 · 청회색 · 올리브색

프로젝트와의 연결: 인증·게시글·실시간 채팅을 모듈별로 구성하면서 하나의 서버 안에서 연결한 학습을 공동 주택의 다른 생활 공간에 비유한다. 실제 서비스의 운영 규모나 복잡한 분산 아키텍처를 주장하는 그림이 아니다.

### 반복 작업을 SKILL로 만드는 법

위치: P02-01-F · 기획 가제: 익숙한 손의 본

오래된 재단대에 같은 곡선의 옷깃 본과 서로 다른 세 벌의 천이 놓여 있다. 재단사는 새 천을 펼치기 전에 옷깃 본을 살피고, 이미 완성된 옷 한 벌의 솔기를 빛에 비추어 확인한다. 벽의 본들은 장식처럼 늘어놓지 않고 몇 개만 남겨, 반복의 숙련과 선택의 신중함이 보이게 한다. 창가의 가위 날과 누른 자국에만 작은 하이라이트를 준다.

구도: 사선 위에서 보는 근접 정물과 반신 인물의 결합. 옷깃 본이 큰 곡선을 만들고, 인물의 시선이 완성된 솔기로 이어진다. 종이 본에는 글자나 숫자를 넣지 않는다.

표현: 연필 드로잉 중심, 천에만 제한적인 수채 채색

색조: 흑연 · 미색 · 세이지 그린 · 바랜 적갈색

프로젝트와의 연결: 발동 조건·작업 범위·참고 자료·검증 방법을 재사용 가능한 지침으로 만든 일을, 상황에 맞는 본을 고르고 완성된 솔기까지 확인하는 재단에 비유한다. SKILL이 생각 없이 반복 실행하는 만능 자동화라는 인상을 주지 않는다.

### 요구사항 게이트 하네스

위치: A02-03 · 기획 가제: 출발하지 않은 등반가

안개 낀 바위 지대에서 등반가가 한 발을 내딛지 않은 채 장비 연결과 앞선 발자국을 살피고 있다. 전경의 눈에는 여러 번 왔다가 돌아온 발자국이 포개져 있고, 중경에는 잠시 멈춘 인물, 배경에는 아직 들어가지 않은 가느다란 능선이 이어진다. 정상이나 승리의 깃발은 보이지 않는다. 그림의 긴장은 앞으로 가는 속도보다 출발 조건을 갖추는 정지에서 나온다.

구도: 낮은 눈높이의 가로 풍경. 인물은 중앙보다 왼쪽에 두고 오른쪽 능선으로 큰 빈 공간을 남긴다. 전경 발자국은 해칭으로 층을 보이되 선형 경로도처럼 연결하지 않는다.

표현: 흑연·목탄 드로잉 + 아주 옅은 청회색 수채

색조: 종이색 · 차콜 · 안개 청색 · 소량의 주홍색

프로젝트와의 연결: 필수 문서 확인 전 변경 도구를 막는 tool gateway를 출발 전 점검과 멈춤으로 대응시킨다. 포개진 발자국은 session_id별 이벤트를 보존해 재생·재시도·인수인계하는 맥락을 뜻한다. 어떤 오류도 발생하지 않는다는 보장은 담지 않는다.

### AI 개발 파이프라인

위치: A02-04 · 기획 가제: 새벽의 발굴을 이어받는 사람

밤샘 작업이 끝나는 발굴 현장에 아침 작업자가 도착한다. 먼저 있던 작업자는 흙층을 그대로 남긴 채 작은 조각이 어디서 나왔는지 손이 아닌 시선과 몸의 방향으로 설명하고, 새 작업자는 그 위치를 살핀다. 전경의 낮은 쟁반에는 연결될 수 있는 파편과 그 곁에 놓인 빈 기록지가 있고, 뒤쪽에는 아직 파지 않은 흙층이 남아 있다. 새벽의 차가운 그림자와 처음 들어오는 금빛이 두 작업자를 가른다.

구도: 허리 높이 시점의 넓은 장면. 두 사람은 화면의 서로 다른 쪽에 두고, 중앙의 보존된 흙층을 공통 초점으로 삼는다. 기록지는 읽을 내용 없는 사물로만 표현한다.

표현: 연필과 펜의 층위 묘사 + 흙색 수채

색조: 흙갈색 · 황토색 · 새벽 청회색 · 옅은 금색

프로젝트와의 연결: 여러 AI 도구와 후속 작업자에게 요구사항·판단 맥락·변경·검증 근거를 저장소 자료로 넘기는 과정을 고고학 작업의 교대에 비유한다. 중앙 흙층은 앞선 결론과 남은 범위를 보존하는 대상이며, 모델이 실제 발굴을 수행한다는 뜻이 아니다.

### 비개발자용 에이전트 IDE

위치: P02-03-F · 기획 가제: 처음 지휘봉을 든 사람

연주 경험이 많지 않은 지휘자가 작은 실내악단 앞에 서 있고, 각 연주자는 서로 다른 악기를 맡아 그를 바라본다. 지휘자 옆의 숙련된 악장이 다른 연주자의 반응을 살피며 첫 호흡을 맞춘다. 무대 전경에는 아직 소리가 나지 않는 악기 케이스가 놓이고, 뒤쪽의 높은 창으로 저녁빛이 길게 들어온다. 음악을 선이나 아이콘으로 그리지 않고, 인물들의 시선과 기다림으로 역할 간 조율을 표현한다.

구도: 관객석 앞줄에서 올려다보는 시점. 지휘자의 뒷모습이 전경의 실루엣이 되고 세 종류의 연주자 군이 서로 다른 깊이에 놓인다. 손은 과장하지 않고 옆모습과 소매로 단순화한다.

표현: 부드러운 흑연 인물화 + 청회색·밤갈색 수채

색조: 웜 그레이 · 밤갈색 · 인디고 · 크림색

프로젝트와의 연결: 비개발자의 자연어 요청을 PM·설계·개발·검증 역할로 나누고 의존성과 판단 맥락을 보이는 IDE를 작은 합주의 조율에 비유한다. 악장이 취합하는 역할은 연관 profitpal 실험에도 연결되지만, IDE 하나가 완성된 제품을 항상 만들어 준다는 성과는 주장하지 않는다.

### TOPIK AI 검증 하네스

대안: 보다 인물 중심으로는 오래된 옷의 자수를 풀지 않은 채 새 무늬를 임시 시침한 복원가를 그릴 수 있다. 다만 SKILL의 재단 장면과 소재가 겹치므로 기본안은 과수원으로 유지한다.

### 자동매매 시스템

### 디자인 룰북

위치: A02-06 · 기획 가제: 놓임을 가르치는 정물 수업

화실의 흰 벽 앞에서 한 사람이 큰 물병과 작은 잔, 가느다란 가지를 놓고 한 걸음 물러나 바라본다. 가장 큰 물병은 빛을 받고 작은 잔은 덜 밝은 곳에 있으며, 천의 접힘이 사물 사이의 간격을 조용히 드러낸다. 전경의 사용하지 않은 사물은 그림자 속에 남겨 무엇을 덜어냈는지 느껴지게 한다. 결과를 평가하는 표정 대신 다시 놓아 볼 수 있는 차분한 시선을 그린다.

구도: 정물화가 화면의 대부분을 차지하고 관찰자의 어깨는 한쪽 가장자리에만 들어온다. 크기·명도·간격으로 위계를 만들며, 자·격자·비례 도식은 그리지 않는다.

표현: 연필 밑그림과 얇은 수채, 물병의 명암은 부드러운 흑연

색조: 백회색 · 따뜻한 회색 · 세이지 그린 · 작은 테라코타

프로젝트와의 연결: 예쁘다는 추상적 요구를 구조·정보 우선순위·타이포그래피·간격·색·반응형처럼 다시 확인하고 수정할 수 있는 기준으로 바꾼 일을 정물의 배치와 리뷰에 비유한다. 특정 미적 공식이 모든 UI를 좋게 만든다는 뜻은 아니다.

## 03 인터랙션과 실험

손길이 세계의 규칙을 바꾸는 작은 극장. 코드와 화면을 직접 그리지 않고, 고르고·옮기고·바라보고·기록하는 인간의 행동이 주변 풍경을 바꾸는 장면으로 인터랙션을 번역한다.

주된 표현: 과슈 회화: 불투명한 무광 색면, 손으로 칠한 가장자리, 붓의 결이 보이는 동화적이되 유아적이지 않은 풍경과 인물

색연필·펜의 세밀한 묘사: 손, 얼굴, 천, 식물, 목재와 도구의 질감을 보강한다. On the Book 3부작에서만 투명 수채를 더해 종이와 여백의 호흡을 연결한다.

### 이전 포트폴리오 경력 지도

위치: A03-01 · 기획 가제: 서로를 기르는 길

굽은 강을 따라 한 사람이 여러 시기의 집과 작업장을 지나간다. 전경에서는 젊은 사람이 가벼운 목재 모형을 만들고, 중경의 작업장에서는 동료들이 같은 물건을 완성하며, 후경에는 그 형태가 변주된 큰 공간이 놓인다. 길은 직선으로 시간을 설명하지 않고 개울을 건너 되돌아가기도 하며, 뒤에서 만든 물건 하나가 앞의 집에서도 발견된다. 길을 따라 놓인 인물의 가방과 붉은 천이 동일인의 경험이 여러 프로젝트로 이어짐을 암시한다.

구도: 높은 곳에서 비스듬히 내려다본 산골 작업 마을. 가장 밝은 길이 S자로 시선을 이끌고 앞의 작은 물건과 뒤의 큰 건물 사이에 형태의 반복을 둔다. 지도 기호·경력 연도·연결선 없이 실제 길과 사람으로 관계를 표현한다.

표현: 과슈 바탕에 색연필로 기와·목재·옷의 주름을 그린 서사적 풍경화

색조: 회녹색 · 황토색 · 살구색 · 군청 그림자

프로젝트와의 연결: 경력과 프로젝트의 관계를 따라 이동하는 Canvas 포트폴리오를 한 사람의 경험이 여러 장소를 연결하는 풍경으로 번역한다. 참고 구조를 자신의 콘텐츠로 재구성한 사실과 관계 탐색에 집중하며, 특정 고용 이력의 실재 풍경처럼 보이지 않게 한다.

진열 방식: 기존 벽면 액자 안의 풍경화. 화면 하단의 길을 과도하게 잘라내지 않도록 주요 인물과 길의 출입을 중앙 안전 영역에 둔다.

### 캔버스 여러 개

위치: V01 · 기획 가제: 등불 하나가 여는 무대들

어두운 인형극 작업실 중앙에 작은 등불 하나가 놓인다. 한 명의 조명사가 등불 주위의 얇은 거울과 천을 돌보자 바닥, 비스듬한 막, 천장 아래 천에 서로 다른 인형극의 빛과 그림자가 맺힌다. 전경에서는 새의 그림자가 날고 중경에는 작은 배가 지나가지만, 모든 장면의 빛은 한 등불에서 온다. 구석의 사람은 장면마다 등불을 늘리는 대신 같은 불을 섬세하게 나누어 쓴다.

구도: 하나의 따뜻한 광원을 중심으로 불규칙한 삼각 구도. 여러 공연면은 균일한 격자나 브라우저 창 모양이 아니라 구겨진 천과 바닥의 서로 다른 각도로 배치한다.

표현: 짙은 과슈 위에 색연필로 빛의 입자와 천의 결을 더한 명암 회화

색조: 먹빛 군청 · 촛불 황토 · 붉은 갈색 · 상아색

프로젝트와의 연결: 여러 위치의 3D 영역을 하나의 WebGL 렌더러로 채우는 자원 공유를 하나의 광원이 여러 무대를 만드는 비유로 설명한다. 실제 구현이 광학 투사라는 뜻은 아니다.

진열 방식: V01 진열장 안에 눕혀 세운 소형 회화 또는 얕은 3면 그림 병풍. 병풍을 택해도 그림은 한 장면으로 이어지고 기존 진열장의 위치·크기는 유지한다.

### 캔버스 · 파티클

위치: A03-02 · 기획 가제: 흩어진 것들이 새가 되는 시간

바닷가 작업장에서 한 사람이 커다란 천을 털자 잘게 부서진 꽃잎과 안료가 바람을 탄다. 화면 왼쪽에서는 색의 조각들이 각자의 소용돌이를 만들고, 중앙에서는 물고기처럼 유영하며, 오른쪽 위에서는 한 무리의 새 형상으로 잠시 모인다. 새의 가장자리는 완전히 닫히지 않아 입자가 흩어졌다가 다시 모일 수 있는 순간으로 남는다. 아래의 잔잔한 바다는 움직임을 받아 색이 겹쳐진 넓은 붓질로 반사한다.

구도: 화면 아래의 작은 인물과 대각선으로 상승하는 큰 입자 떼를 대비한다. 좌우의 여러 움직임은 같은 바람 속에 속하고 점을 수학적으로 균일하게 배치하지 않는다. 가까이에서는 개별 붓점, 멀리에서는 하나의 생명체가 보인다.

표현: 과슈의 큰 면과 수채의 번짐 위에 물감 튀김·마른 붓 점묘를 겹친 혼합 회화

색조: 바다 군청 · 산호색 · 꿀빛 노랑 · 백악색

프로젝트와의 연결: canvas-lab의 다양한 입자 움직임은 왼쪽의 서로 다른 흐름으로, particle의 형태 변환은 흩어진 조각이 새 형태를 만드는 오른쪽으로 구별한다. 입자 자체를 장식 배경에 그치지 않고 집단 형태가 생기는 주인공으로 삼는다.

진열 방식: 기존 벽면 액자. 입자 떼 전체의 실루엣이 멀리서도 읽히게 크고 단순한 주 동선을 만든다.

| 포함 항목 | 그림 속 세부 모티프 |
|---|---|
| 캔버스 · 파티클 | 같은 바람 속에서 소용돌이·물결·흩날림을 달리 만드는 왼쪽의 안료 조각 |
| 파티클 형태 변환 실험 | 오른쪽 위에서 흩어진 조각들이 커다란 새의 윤곽으로 결집하는 순간 |

대안: 더 회화적인 안은 인물을 없애고 거대한 정원 나무의 꽃잎이 물고기 떼로 바뀌는 초현실 정물·풍경을 그린다. 반대로 동작의 원인을 분명히 하려면 현재의 천을 터는 사람을 유지한다. 두 안 모두 점으로 만든 로고나 글자를 쓰지 않는다.

### 스크롤 연동 3D

위치: V02 · 기획 가제: 손끝이 내리는 풍경

오래된 극장에서 한 사람이 두 손으로 긴 천 두루마리를 조금씩 내린다. 천에 그려진 산길은 아래로 내려갈수록 해안으로 이어지고, 중앙의 여행자는 같은 길을 따라 더 깊은 공간으로 들어간다. 위쪽에는 아직 말린 새벽의 산이, 중앙에는 햇빛 드는 계곡이, 아래쪽에는 가까운 파도가 한 장의 연속된 풍경으로 놓인다. 천을 당기는 손과 공간을 통과하는 여행자의 몸이 서로 다른 크기로 공존하는 초현실적 장면이다.

구도: 내리는 천의 세로 움직임을 깊은 원근의 길과 연결한다. 진열장의 낮은 시점에서도 손과 천의 가장자리, 사라지는 길이 보이도록 중앙에 압축한다.

표현: 종이결이 드러나는 과슈와 색연필, 천 가장자리만 얇은 붓으로 묘사

색조: 바랜 청록 · 살구빛 모래 · 군청 · 상아색

프로젝트와의 연결: 스크롤 입력의 진행량이 3D 장면 진행과 이어지는 관계를 두루마리를 내리는 손과 여행의 깊이가 함께 달라지는 장면으로 치환한다. 스크롤 UI나 진행률 바를 그리지 않는다.

진열 방식: V02 진열장 안의 얕게 기울인 소형 회화. 선택적으로 같은 그림을 낮은 두루마리 형태의 지지체에 인쇄할 수 있으나 실제 집기나 동선은 변경하지 않는다.

### 물체 감지

위치: A03-03 · 기획 가제: 이것은 무엇일까

늦은 오후의 벼룩시장에 작은 물건들이 한 장의 천 위에 펼쳐져 있다. 무릎을 굽힌 관찰자는 조개처럼 보이는 물건을 들여다보고, 맞은편 아이는 그것이 작은 찻잔 뚜껑이라고 알려 주듯 실제 잔을 내민다. 옆의 보조자는 닮은 물건들을 서로 겹치지 않게 놓을 자리를 찾고 있다. 손의 선택과 재배치가 장면의 중심이며, 물건 둘은 처음 보았을 때 생기는 오해를 즐겁게 드러낸다.

구도: 관찰자·아이·보조자의 손이 이루는 삼각형 가운데에 물체를 둔다. 전경의 커다란 천과 사물은 선명하게, 시장 골목의 인물은 느슨하게 그려 인식과 확인의 행동에 시선이 머물게 한다.

표현: 과슈 정물·인물화에 색연필로 사물의 표면과 손을 세밀하게 묘사

색조: 크림색 · 테라코타 · 회녹색 · 짙은 남색

프로젝트와의 연결: 사진의 물체를 감지하는 동작뿐 아니라 잘못된 추정 뒤 사용자가 다시 선택하는 흐름과 결과끼리 겹치지 않게 배치하는 문제를 세 사람의 관찰·확인·정리 행동으로 반영한다. 감지 모델이 항상 맞는다는 인상을 피한다.

진열 방식: 기존 벽면 액자. 중심 사물과 손의 대비를 높이고 사물에 이름표·사각 검출 상자·설명 카드가 붙은 그림은 만들지 않는다.

### 3D · 아이소메트릭

위치: V03 · 기획 가제: 방을 조율하는 사람들

지붕을 걷어 낸 작은 작업실에 다섯 사람이 각자의 일을 한다. 한 사람은 가구를 옮기고 다른 사람은 천장등의 방향을 바꾸며, 책상 위에서는 손으로 깎은 모형을 처음 방 안에 놓는다. 높은 의자에 오른 화가는 같은 공간을 다른 각도로 살피고, 바닥의 작은 인물은 멀리 놓인 붉은 실뭉치를 향해 걸어간다. 벽시계의 추와 흔들리는 천으로 시간이 지나며 장면이 계속 움직임을 암시한다.

구도: 아이소메트릭 감각의 내려다보는 구도이지만 방의 정확한 기존 모델을 베끼지 않는다. 상자 도해보다 생활감 있는 하나의 방으로 그리고 인물과 사물의 관계를 중심에 둔다.

표현: 과슈 위 색연필의 건축·인물 드로잉. 손으로 그린 원근의 작은 흔들림을 허용

색조: 버터색 · 회녹색 · 호두색 · 군청 · 산호색

프로젝트와의 연결: 가구와 조명·모델·카메라·캐릭터 이동을 배운 다섯 실험을 하나의 방을 완성하는 서로 다른 사람의 행동으로 묶는다. 인터페이스 패널이나 조절 손잡이를 직접 그리지 않아도 어떤 측면을 조율하는지 읽힌다.

### 포켓몬 도감

위치: A03-04 · 기획 가제: 수집가의 야외 수업

풀과 얕은 물과 햇빛 드는 돌이 만나는 숲 가장자리에서 자연 관찰가가 낮게 앉아 있다. 서로 다른 속성의 친숙한 포켓몬들이 각자 어울리는 서식처에서 고개를 내밀고, 관찰가는 펼친 종이를 차례로 넘기며 찾던 개체를 확인한다. 가까운 풀잎 아래 숨은 작은 개체와 뒤편의 큰 그림자가 관찰의 즐거움을 만든다. 그림 속의 도감은 글과 화면 대신 연필로 그린 큰 실루엣 몇 개만 담는다.

구도: 식물 도감의 판면이 아니라 한 번의 자연 관찰 장면. 풀·물·따뜻한 돌의 세 환경이 자연스럽게 만나며 찾고 있는 대상 한 마리에 가장 밝은 빛을 준다.

표현: 색연필 중심의 세밀한 생태 일러스트에 과슈로 빛과 식생의 큰 면을 보강

진열 방식: 기존 벽면 액자. 서식처 세 곳이 작은 장면의 격자로 잘리지 않고 한 풍경으로 이어진다.

### 3D 공간 만들기

아직 페인트가 마르지 않은 마을의 길에 한 사람이 첫 발을 디딘다. 전경에는 작은 집의 지붕과 젖은 돌길이 크게 보이고, 중경의 빵집과 광장을 지나 후경의 언덕까지 길이 이어진다. 작업복 차림의 제작자는 마지막 나무를 심은 뒤 붓을 내려놓고 그 사람과 함께 길을 걸어간다. 완성된 오브젝트를 구경하는 풍경보다 그것들이 실제로 걸을 수 있는 장소가 되는 순간을 그린다.

### 능력치 카드 게임

위치: A03-05 · 기획 가제: 친구의 또 다른 얼굴

늦은 오후의 식탁에서 친구 둘이 서로의 초상 패를 마주 놓는다. 패에서 몸을 일으킨 듯한 두 수호정령은 각각 주인의 얼굴 특징을 닮았지만 한쪽은 꽃으로 된 갑옷을, 다른 쪽은 물결로 된 망토를 두르고 있다. 친구들은 공격적인 결투보다 뜻밖의 능력을 발견한 듯 웃으며 다음 패를 내민다. 뒤쪽의 조용한 보관함에는 이전에 만든 초상 패들이 얇은 꽃잎처럼 겹쳐 놓여 있다.

구도: 맞잡지 않은 두 손과 두 정령의 시선이 원을 이루는 인물화. 숫자·게이지·게임 카드의 테두리를 쓰지 않고 각자의 성격이 다른 정령의 재료와 몸짓으로 능력 차이를 표현한다.

표현: 과슈의 선명한 인물과 상상 동물, 색연필로 얼굴·식탁·옷감을 보완한 회화

색조: 산호색 · 진한 물빛 · 꿀빛 노랑 · 상아색 · 군청

프로젝트와의 연결: 얼굴 사진으로 카드를 만들고 계정에 저장한 뒤 친구와 대결하는 흐름을 닮은 초상·보관된 패·친구와의 교환으로 구체화한다. 정령은 능력치 생성의 판타지 비유이며 실제 감지 결과나 인물 성격을 판정한다는 뜻은 아니다.

진열 방식: 기존 벽면 액자. 우스운 얼굴 합성처럼 보이지 않도록 친구의 표정은 존중감 있게 그리고 정령 쪽에 과장을 집중한다.

대안: 인물의 얼굴이 부담스럽다면 유랑 초상화가가 두 친구의 초상을 그리는 장면으로 바꾼다. 완성된 초상 속 인물만 서로 다른 환상 의상을 입고 대결 자세를 취하고, 실제 친구들은 바깥에서 웃으며 구경한다. 카드가 곧 액자가 되는 구성은 피하고 천 위에 놓인 초상 종이로 그린다.

### 3D 포트폴리오 구현

### React 학습기

위치: A03-END · 기획 가제: 개장 전날의 작은 공방

봄 축제 개장을 앞둔 공방에서 한 견습생이 커다란 작업 종이를 만들고 옮기며, 그 곁의 정원사는 바뀐 화분 하나만 새 흙으로 갈아 준다. 이 두 행동이 화면을 크게 차지하고 나머지 학습의 흔적은 재단한 천·접힌 차양·조용한 영사기·미완성 종이처럼 주변에 작게 놓인다. 중경의 수선대와 후경의 빈 무대가 한 공간으로 이어져 학습의 시작과 조금씩 완성하는 시간을 함께 보여 준다. 모든 소품을 한눈에 알아보게 만들지 않고 손의 움직임과 물건을 돌보는 태도에 먼저 마음이 머무는 그림으로 그린다.

구도: 가로 7:5의 끝 벽 액자를 채우는 단일 대작. 두 큰 행동과 손에 화면의 60% 이상을 주고, 나머지는 주변 소품·옷감·작업 흔적과 작은 배경 행동에 계층을 두어 배치한다. 26개 모티프가 동등하게 주의를 요구하는 찾기 그림으로 만들지 않는다. 균일한 칸·번호·26개 아이콘·작은 프로젝트명을 넣지 않으며, 화면 전체는 두 사람과 하나의 따뜻한 작업실로 먼저 읽힌다.

표현: 과슈의 무광 색면 위에 색연필을 촘촘히 겹친 큰 서사 회화. 전체를 같은 손맛으로 묶고 주요 얼굴과 손만 상세하게 그린다.

색조: 따뜻한 상아색 · 산호색 · 회녹색 · 군청 · 꿀빛 황토

프로젝트와의 연결: 26개를 모두 동일한 React 앱으로 보이게 하지 않고 상태·라우팅·요청·스타일·기초 JavaScript 등의 실제 학습 차이를 각 행동으로 보존한다. assignment·data_structure·drag-n-drop·canvas-test가 React 밖의 기초 학습이라는 점도 수작업 모티프로 구별한다. 그림 속 상징만으로 26개를 식별하도록 강요하지 않으며 프로젝트 상세의 기존 선택 기능은 그대로 유지한다.

진열 방식: 끝 벽의 기존 대형 액자 한 점. 전체 실루엣은 몇 개의 큰 작업 무리로 정돈하고 가까운 보기에서만 작은 모티프를 발견하도록 제작한다.

## 먼저 제작할 여섯 장면

세 방에서 두 장면씩 먼저 제작해 실제 공간에서 재료감과 명암을 비교한다. 긴 설명이 없어도 주제가 읽히는지, 작은 크기에서 구별되는지 확인한 뒤 나머지 그림에 같은 재료감을 적용한다.

- 센서 3D 시각화 대시보드: 온실의 숨 (A01-03)
- CONNECT BEE: 벌이 깨어나는 온도 (A01-04)
- Planit AI 기획 워크스페이스: 아직 접붙이지 않은 가지 (A02-END)
- VIVE 독서 보조 도구: 읽고 난 뒤에 남은 정원 (A02-09)
- 캔버스 · 파티클: 흩어진 것들이 새가 되는 시간 (A03-02)
- On the Book · 책 속 3D 장면: 빛을 빌려주는 항구 II — 들어가기 (V09)

On the Book은 중앙의 3D 장면을 먼저 제작하고 도서 선택·콘텐츠 관리의 두 장면으로 이어가 세 폭의 인물과 색조를 맞춘다.

세부 항목과 모티프의 대응은 [구조화된 회화 기획](portfolio-painting-plan.json)에 함께 보관한다. 기존 프로젝트의 기술 설명과 체험 주소는 현재 데이터 그대로 유지한다.
