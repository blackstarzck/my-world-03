# 포트폴리오 작품 배치와 관람 동선

기존 세 전시실의 실제 좌표와 집기를 유지하는 배치안이다. 41개 작품군과 95개 항목을 49개 전시 위치에 연결한다. 앱 개발과 집기 이동은 포함하지 않는다.

## 배치와 동선의 기준

각 방은 12m × 24m이고 중앙 로비에 연결된 출입구 하나를 함께 사용한다. 전체 관람은 입구 → 01 → 로비 → 02 → 로비 → 03 → 로비 → 출구 순서다. 각 방은 입구에서 왼쪽으로 시작해 깊은 곳을 돌아 오른쪽으로 복귀한다.

01·02의 19곳은 외곽 벽 11곳과 독립 전시벽 네 개의 앞뒤 8면이다. 03은 왼쪽 벽 5곳·끝 벽 1곳·진열장 10곳이다. 03 오른쪽에는 기존 회화 위치가 없으므로 새 액자를 그리지 않는다.

F는 입구를 향한 면, B는 뒤쪽 면이라는 계획용 표기다. 모든 위치와 크기는 [기존 설계 데이터](../src/world/design-basis.json)를 따른다. 감상 위치와 이동 구간은 기존 보행 충돌 모델로 확인했다. 실제 앱의 포커스·가림·화면 비율 검수는 적용 단계에 남는다.

iframe은 선택한 앱 하나만 켠다. 캡처·자료 작품은 화면 선택과 확대를 제공한다. 조건부 체험은 인증 데모·배포 정비가 준비되기 전까지 자료로 전시한다. Planit은 로컬 캡처 5장을 사용한다.

## 작품 설명의 층위

공간 안의 명패는 작품명과 실제 프로젝트명, 핵심 설명 한 문장, 실제 역할, 체험 상태로 짧게 구성한다. 시적인 작품명 바로 아래에 프로젝트명을 항상 표시한다. 포커스 후 우측 패널은 문제와 결과를 설명하는 두 문장, 실제 담당 범위, 관람 포인트, 구현·협업 근거, 서비스·GitHub 링크 순서로 구성한다.

운영 여부와 전시 방식은 분리해 표시한다. Planit은 로컬 앱·검수용 샘플 데이터, 밀리 관리자는 개인 프로젝트, DADOKe는 기획·외주 커뮤니케이션, React 연작은 학습·클론 성격을 명시한다. 출처가 없는 성과 수치와 구체적인 담당 역할은 추가하지 않는다.

진열장은 멀리서 볼 때 모형을 유지한다. 포커스 시 정면에 평면 체험 화면을 제공하고, 작은 화면에서는 작품 영역을 확대하는 방식을 제안한다. 우측 설명과 바깥 닫기는 유지한다.

명패 문구: “책을 고르는 화면에서 이야기 속 장면으로 이어집니다.”

우측 설명: On the Book의 도서 목록과 상세 화면입니다. 배포본에서 도서 4권 표시와 앨리스 상세 이동을 확인했으며, 관람자는 작품 안에서 책을 선택해 살펴볼 수 있습니다.

관람 포인트: 도서 목록 → 앨리스 상세 → 장면 선택.

### V09 On the Book · 3D

명패 문구: “책의 한 장면을 걸을 수 있는 3D 공간으로 펼쳤습니다.”

우측 설명: On the Book의 앨리스 첫 장면을 실제 배포본으로 엽니다. 도서 상세에서 장면으로 이동하고 WebGL 화면이 표시되는 흐름을 확인했습니다.

관람 포인트: 앨리스 첫 장면과 이야기·공간의 연결.

### V08 On the Book · CMS

명패 문구: “이야기의 뒤편에서 콘텐츠와 장면을 준비하는 관리 도구입니다.”

우측 설명: On the Book의 관리자 화면을 사용자 서비스·3D 장면과 연결해 소개합니다. 현재 확인 범위는 로그인 화면이며, 관람용 인증 데모가 준비되기 전에는 화면과 구조 자료로 전시합니다.

관람 포인트: 사용자 서비스와 관리 도구의 연결 구조.

### V07 이동·공간 게임

명패 문구: “입력과 판정이 만나는 순간, 화면은 놀이가 됩니다.”

우측 설명: bridge·first-person-perspective·lets-fps를 선택하는 이동·공간 진열장입니다. 앞의 두 프로젝트는 배포 화면을 체험하고 lets-fps는 관람용 인증 데모가 준비될 때까지 자료로 전시합니다.

관람 포인트: 격투·아케이드 또는 이동·공간 실험 선택.

### V06 격투·아케이드

명패 문구: “입력과 판정이 만나는 순간, 화면은 놀이가 됩니다.”

우측 설명: NEON FIST와 GAME CABINET을 선택하는 격투·아케이드 진열장입니다. NEON FIST는 iframe에서 시작과 키보드 입력을 확인했으며, GAME CABINET 내부 외부 게임의 동작은 개별 확인 대상으로 둡니다.

관람 포인트: 격투·아케이드 또는 이동·공간 실험 선택.
