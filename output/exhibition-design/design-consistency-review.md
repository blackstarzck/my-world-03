# 평면도와 단면·전시 요소 설계도 연계 검수

검수일: 2026-10-06  
검수 대상: master-exhibition-plan.png / sections-and-details.png / dimension-reference.md  
방법: 원본 해상도 이미지 시각 대조, 치수표 대조, 주요 수치의 합계와 여유 공간 확인  
수정 여부: 이번 검수에서는 이미지와 기존 치수표를 변경하지 않았다.

## 판정

**부분 연계. 주요 숫자와 콘셉트는 맞지만, 동일한 3D 공간을 재현할 수 있는 통합 설계도 상태는 아니다.**

평면도와 단면 이미지가 하나의 확정된 공간을 서로 다른 방향에서 보여 준다는 근거가 부족하다. 현재 단면 이미지는 원근이 있는 공간 설명 그림에 가깝다. 수치가 맞는 것과 같은 공간의 벽·창·가구가 맞는 것은 별개다.

### 수치 관계 확인

- 진열장 중심을 중앙선 좌우3000에 놓고 폭1200으로 만들면 중앙 통로는6000-1200=4800.
- 방 전체 폭은3600+4800+3600=12000. 양쪽3600은 벽에서 진열장의 안쪽 면까지이며, 벽과 진열장 바깥 면 사이 간격은2400.
- 창 높이는5400-900=4500.
- Concept02 보 깊이는5000-4400=600.
- Concept02 조명 높이4200은 보 아래4400보다200 낮다.
- 높이1000 받침대에 높이700 조각을 놓으면 합계1700. 높이2400 진열장 안쪽 상부 여유는 외곽 높이 기준700.
- 전시실 한 곳의 내부 면적은12×24=288㎡.

## 확인된 불일치와 누락

### 1. 단면을 자른 위치와 보는 방향이 없다 — 먼저 수정 필요

최종 평면도에 단면을 자르는 선, 단면 번호, 보는 방향 표시가 없다. 상세 설계도도 공간 이름으로만 구분되어 있으며, 어느 위치를 자른 그림인지 명시하지 않는다.

따라서 전시 벽의 앞뒤 순서, 창이 있는 벽의 방향, 단면에 보이는 기둥과 벤치가 평면도의 어떤 요소인지 검증할 수 없다. 원근이 있는 실내 그림은 정확한 단면을 대신하지 못한다.

수정 방향: 평면도에 전시실별 단면 위치와 보는 방향을 지정하고, 같은 번호를 붙인 폭 방향 단면과 필요한 길이 방향 단면을 작성한다.

### 2. Concept03 측면 창과 작품 벽이 맞지 않는다 — 먼저 수정 필요

상세 설계도에는 크게 이어진 측면 창이 있다. 평면도에는 이 창의 범위와 창틀 위치가 명확히 나타나지 않으며, 긴 외곽 벽에 그림이 배치되어 있다.

치수표는 도면 아래쪽 외곽 긴 벽의 입구부터2000~22000을 창 구간으로 정한다. 해당 벽을 그대로 큰 창으로 만들고 평면의 그림도 그대로 배치하면 작품과 창이 같은 벽 구간을 점유할 수 있다.

수정 방향: 창 구간과 불투명 작품 벽을 평면에서 먼저 분리하고, 단면에 같은 방향과 구간을 반영한다. 창 하단900, 상단5400이라는 숫자 자체는 일치한다.

### 3. 로비 벤치 형태와 Concept01 벤치 배치가 다르다 — 수정 필요

평면도 로비에는 원형 받침대를 둘러싼 곡선 벤치3개가 보인다. 로비 상세 그림의 앞쪽 벤치는 직선 형태로 표현되어 있다. 단면 위치도 없어 같은 벤치를 보고 있는지 확인할 수 없다.

Concept01 상세 그림에는 중앙 벤치가 보이지만, 최종 평면도의 해당 공간에는 그 벤치의 위치가 명확히 그려져 있지 않다. 치수표의 일반 벤치 규격2000×600×450은 있어도 평면의 확정 배치와 이어지지 않는다.

수정 방향: 벤치 종류·수량·위치를 평면에 확정하고 같은 요소를 단면에 반영한다. 로비 곡선 벤치와 일반 직선 벤치를 구분한다.

### 4. 로비 외곽과 곡선 연결부를 치수표만으로 재현할 수 없다 — 먼저 수정 필요

평면도의 중앙 공간은 원형 동선과 넓은 곡선 연결 어깨, 여러 짧은 벽·기둥을 포함한다. 지름18000이 어느 경계까지의 치수인지 명확한 지름 치수선으로 표시되어 있지 않다. 원형으로 그려진 주황 점선은 이동 경로이므로 로비 벽의 경계로 확정할 수 없다.

치수표의 기본 바닥은 지름18000 원형 로비, 폭4000 연결부, 세 직사각형 전시실을 합친 단순 형태다. 같은 문서는 넓은 곡선 연결 어깨와 기둥을 참고 표현으로 분류한다. 따라서 이 숫자만 따르면 그림의 외곽 형태와 기둥 배치가 그대로 나오지 않는다.

수정 방향: 로비의 지름 기준선을 명확히 하고, 실제 외곽 곡선의 반경·접점, 짧은 벽과 기둥의 위치·크기, 연결부 폭과 길이의 기준점을 정한다.

### 5. 천창·기둥·연결부 높이의 대응이 부족하다 — 추가 명시 필요

- Concept01 상세 그림과 치수표에는 천창이 있지만, 평면에는 천창3개의 위치를 확인할 수 있는 별도 표시가 없다.
- Concept02의 점선 천창과 단면의 두 천창은 큰 방향이 맞지만, 전체 길이와 보가 만나는 구간이 도면에서 확정되어 있지 않다.
- 로비 상세 그림의 천창과 여러 기둥은 평면도의 구체적 위치 및 크기와 연결되지 않는다.
- Concept02는 높이5000이고 로비는6000이다. 연결부에서1000의 높이 차가 어떻게 바뀌는지 두 이미지만으로 확인할 수 없다.
- 전시실 입구의 짧은 벽·유리처럼 보이는 요소는 각각의 기능·높이·좌표가 명시되지 않는다.

수정 방향: 천장 배치도와 연결부 단면을 추가하고, 천창·기둥·창틀에 동일한 위치 기준을 사용한다.

### 6. 축척 표기가 혼동을 준다 — 수정 필요

평면도에 비축척 그림을 뜻하는 NTS와0~5~10m 축척 막대가 함께 들어 있다. 지금처럼 비축척 그림으로 유지한다면 축척 막대로 화면을 재는 방식은 사용하면 안 된다. 상세 그림에도 원근이 있어 화면상의 길이를 실제 치수로 환산할 수 없다.

수정 방향: 축척 막대를 제거하고 수치만 쓰는 제안도임을 분명히 하거나, 전체 도형과 치수선이 실제 축척에 맞는 평면도로 다시 작성한다.

### 7. 개별 전시 요소의 치수와 좌표가 평면에 연결되지 않는다 — 추가 명시 필요

전시 벽3000×300×3600, 진열장1200×1200×2400, 받침대600×600×1000 등의 상세 규격은 있다. 그러나 평면의 각 요소에 같은 번호와 설치 위치 치수선이 없다.

치수표의 전시실 중심 좌표, 전시 벽8000/16000, 진열장3000/7500/12000/16500/21000은 별도로 제안한 값이다. 현재 평면 이미지에는 이 배치 수치가 표시되어 있지 않아 그림과 정확히 일치하는 좌표라고 검증할 수 없다.

수정 방향: 전시 요소에 번호를 붙이고 규격표, 평면 배치 치수, 단면 높이를 연결한다.

## 수정 순서

1. 평면의 외곽, 로비 경계, 연결부, 창과 작품 벽을 확정한다.
2. 벤치·전시 벽·진열장·기둥에 같은 번호와 배치 치수를 붙인다.
3. 그 평면에서 단면을 자를 위치와 보는 방향을 정한다.
4. 같은 공간을 기준으로 폭 방향 단면, 길이 방향 단면, 천장 배치도를 작성한다.
5. 전체 치수와 높이, 수량을 다시 대조한다.

## 사용 가능 범위

현재 자료는 세 가지 분위기와 기본 규모를 결정하는 용도로 사용할 수 있다. 두 이미지를 그대로 한 공간으로 재현해야 하는 3D 제작 기준으로 확정하기에는 위 수정이 필요하다.

이번 검수는 이미지와 문서의 일관성 검토다. 실제 3D 모델에서의 형상·충돌 검증은 하지 않았다.
